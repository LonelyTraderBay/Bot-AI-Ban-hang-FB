## 2. Contract chung cần chốt trước code

1. **Phân tầng đúng nguồn:** token nguyên tử → output sinh → theme/layout/visual → shared owner → route/module consumer. Hành vi/route/quyền/query/payload vẫn lấy manifest/OpenAPI/UX contract. Tài liệu không tạo scale thứ hai.
2. **Phân loại owner:** presentation, composition, behavior, application shell, feature-local. Shared UI behavior như QueryState/Toolbar/MutationButton/EditDialog được giữ ở shared; network/cache/permission/intents không chuyển vào composition. Feature-local có quyền giữ schema/columns/chart/conversation/workflow riêng.
3. **API hữu hạn không đồng nghĩa mọi giá trị đều là enum:** name/value/text/ReactNode/domain rows là dữ liệu; finite geometry/flow keys chỉ mở cho workflow thật. Không thêm `sx`, `style`, `className`, arbitrary props hoặc spacing number vào shared public API. Giá trị responsive/geometry phải kiểm provenance và reflow; không khóa width chart/table thành spacing scale.
4. **Slot là nội dung, không là đường vòng style:** actions/action/children/value/icon/extra/column.render vẫn dùng ReactNode để giữ code đơn giản. Source gates kiểm code tạo node và descendant styles; component owner giữ gap/inset. Không dựng slot renderer/ID registry/schema engine thay React composition. MUI `slotProps`/RHF spreads hợp lệ cho input state, event, name, ref, readOnly, maxLength, ARIA; layout/visual override qua nested slot vẫn chịu cùng token/owner checks.
5. **Một owner cho mỗi mép:** page gutter/main inset ở Shell; shared group giữ inter-child gap; Panel/dialog giữ inset; con giữ internal rhythm. Hai surface phân biệt có inset riêng hợp lệ. Dạng fragment/wrapper/query state không được giấu owner trùng.
6. **Gap khác distributed whitespace:** `justifyContent="space-between"`, intrinsic height, multiline text, wrapped rows và alignment tạo khoảng trống ngoài CSS `gap`. Không coi mọi khoảng mép bằng gap computed. Contract phải ghi gap tối thiểu + distribution/wrap/align, rồi đo đúng cặp mép ở state/viewport thật.
7. **Semantics/ARIA/ref có owner:** composition không thành Button bằng `role="button"`; native form giữ submit/ref/noValidate/draft. Dialog title/content/actions và InputLabel/helper text giữ ID/focus semantics. Không thêm một lớp form state thứ hai chỉ để làm thống nhất spacing.
8. **Consumer compatibility:** giữ tên export/props/behavior đang dùng trừ migration có bằng chứng; thêm named variant khi inventory thấy nhu cầu thật; cập nhật mọi consumer + fixtures cùng batch. Không silently đổi default gây lệch consumer khác; không duy trì alias/cơ chế cũ vô thời hạn.

## 6. Những điểm §16 cần bổ sung hoặc làm rõ

1. **Full shared closure includes21 existing components.** Existing composition gate's six APIs do not exhaust Panel geometry/PageHeader actions/DataTable render slots/Dialog/MutationButton behavior. Policy catalog gate should reconcile all27 export APIs against implementation without replacing all explicit TypeScript with schema engine.
2. **State/slot profiles are many-to-one per route.** Collection route contains dialog/form/detail/empty/lookup slots. A single route profile/hash or default-state screenshot doesn't cover variants. Include root/auth/no-Shell and portal states, named slots, local visual owners and CSS/asset boundary.
3. **Safe metadata vs visual escapes:** MUI InputProps/inputProps/slotProps and RHF spreads have real usage. Negative checks must reject injected sx/style/className/spacing while valid name/ref/event/validation/adornment remains PASS. Known runtime data spreads can have typed contracts; unknown style provenance cannot be clean.
4. **Transparent render output and wrapping:** QueryState and DetailLine return fragments/multiple DOM nodes. Parent's logical React child isn't necessarily one DOM group. Rules must not declare every fragment unsupported or every nested inset bad; fixture+render owner match specific relation.
5. **Distributed whitespace measurable separately:** source `gap=16` doesn't constrain `space-between` to16 actual edge gap. Define expected relation/direction/row/edge box/visibility/content-ready metadata for measurements, don't enforce glyph-pixel-distance from screenshots as CSS gap.
6. **Pager cross-field payload gap:** current OpenAPI Page:31684–31716 has nextCursor nullable and hasMore boolean, no cross-field constraint. components:242 next disabled only `!page.hasMore`; handler sets cursor only truthy nextCursor. This is a reproducible source-condition enabled-no-op risk, not browser-confirmed current demo data bug. Add frontend targeted failure fixture before any runtime fix; keep Backend out of scope.
7. **Catalog-native semantic coverage:** panel action/subtitle omitted without title, component roles cannot emulate interactive elements, stat value inside p requires valid content, clipboard feedback lifecycle and dialog submission/error owner should be classified in tests. No automatic runtime refactor from structural observation.
8. **Assets/fallback ownership:** standalone PWA SVG/manifest/source index metadata aren't CSS runtime token consumers; assign validation/provenance rather than suppress or copy new colors. Native root error fallback is real UI outside shared catalog.
9. **Backward-compatible batching:** no bulk API renaming/splitting; close source/style gaps first, then confirmed owner bugs, then only proven profile variants; validate callbacks/DOM semantics per batch. Rest JSX isn't debt by tag count.
