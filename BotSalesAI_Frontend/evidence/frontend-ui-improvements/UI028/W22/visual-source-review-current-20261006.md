## Reference correction and decision

The initial contract draft incorrectly used R17 as a form reference and R20 as a collection reference. Reviewing their actual route titles and captures caught the mismatch before W22 closure. R03 now falls back to the shared semantic auth/form profile; R34 compares with R38's actual toolbar/table/pager composition. The contract records this correction. For future tasks, SPC-048 now requires proving a reference with route ID/path/title and its rendered/source artifact; shared module or domain names alone do not qualify.

All 16 route/state/viewport pairs were captured at 390×844 and 1280×900. Paired render data reports zero API writes, page errors, and document horizontal overflow; the table component's documented internal horizontal scroll is not counted as page overflow. The responsive/dialog tests cover widths 320/390/768/1280/1440 and dialogs at 320/390/1280. The four layout tests pass in Chromium and Firefox; existing onboarding/team/privacy/audit behavior and privacy permission tests pass in both engines.
