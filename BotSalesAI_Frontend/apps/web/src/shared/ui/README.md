# Shared UI — API hiện có, contract mục tiêu và quyền sở hữu

**API catalog:** mô tả symbol/types và owner của API hiện có; [plan §16.6](../../../../../docs/FRONTEND_UI_IMPROVEMENT_PLAN.md#ui-rollout-status) là nguồn status duy nhất. Kết quả kiểm source, consumer và rendering có log/fingerprint tại [evidence report](../../../../../evidence/REPORT.md); các S10/S11/S14/S15 cũ là snapshot theo scope của chúng. Lý do thiết kế trước implementation lưu tại [§16.17](../../../../../docs/FRONTEND_UI_IMPROVEMENT_PLAN.md#preimplementation-review-20261007).

**Catalog v2.3 · 09/10/2026 · Chỉ Frontend.** Nguồn quy định duy nhất: [standard v1.29, SPC-001–075](../../../../../docs/FRONTEND_SPACING_STANDARD.md). Thực hiện [workflow §0](../../../../../docs/FRONTEND_SPACING_STANDARD.md#unified-workflow), theo thứ tự [plan v16.0 §16](../../../../../docs/FRONTEND_UI_IMPROVEMENT_PLAN.md#steel-plan). Catalog mô tả API và owner; không tạo thang giá trị, checklist hoặc ledger thứ hai.

**CURRENT** mô tả source/types được đối chiếu bằng TypeScript symbol và consumer thật. **TARGET** là invariant/tiêu chí cần giữ và kiểm mỗi lần thay đổi, không phải một backlog tất cả chưa implement. Catalog có **22 component functions + 6 composition functions**; `Column<T>` là supporting type của DataTable. Tests khám phá các file shared UI TSX và đối chiếu toàn bộ export/props/owner với catalog, kiểm direct rendering. Kết quả chạy hiện hành chỉ ghi tại evidence report; số API không chứng minh mọi nhánh ngữ nghĩa. Hai notice không có production consumer có lifecycle conditional rõ, không tạo consumer giả.

## 1. Chọn owner và phân loại public API

Canonical tokens → output sinh → theme/layout/visual → shared owner → module consumer. Giá trị nguyên tử ở tokens; theme giữ mặc định primitive; layout/visual giữ semantic roles; component giữ inset/gap nội bộ; module giữ schema, columns, actions, payload và workflow. API/model hooks giữ query, cache, abort, permission và command state. Không thêm provider, thư viện hoặc universal form/table/slot engine.

| Nhóm public input | Contract dùng chung | Kiểm chứng cần giữ |
|---|---|---|
| Dữ liệu và nội dung | Text, value, rows, ReactNode và callbacks được phép; không biến mọi dữ liệu thành enum | Escaping, locale, precision, unknown state, semantics và kết quả quan sát được |
| Visual, flow và geometry | Dùng named variants hiện có; kiểm finite keys, values và nguồn responsive. Không mở generic sx/style/className hoặc gap/p/m | Fixture chặn injection; fixture hợp lệ cho cast, union và geometry; reflow và từng nhánh |
| Slots | children/actions/action/icon/value/extra/column.render dùng React composition; owner và nội dung có trách nhiệm riêng | Kiểm source tạo node, nested styles, portal và state; không miễn kiểm descendant |
| Metadata và native behavior | Chỉ hỗ trợ ID, ARIA, data, ref, submit và events được khai báo rõ; mở rộng đúng owner khi consumer thật cần | Forward name/ref/submit/RHF/draft đúng; giữ accessibility; không giả interactive element bằng role |
| MUI/RHF nested input | InputProps/inputProps/slotProps/Controller/register/field được giữ dữ liệu, events, ref, validation và adornment hợp lệ | Phân biệt behavior spread với visual override; nguồn style không xác định không được nhận PASS |

**Một boundary chỉ có một owner.** Shell giữ mép trang; parent composition giữ gap giữa các con; Panel/dialog giữ surface inset; con giữ nhịp nội bộ. Với Panel có title, đo từ mép dưới nội dung header cuối đang hiển thị đến mép trên nội dung body đầu theo SPC-014; child không cộng top inset. Các surface có border và mục đích riêng được giữ inset riêng. Fragment/query/wrapper có thể tạo nhiều DOM siblings: kiểm quan hệ owner thực, không suy từ số React children.

**Outlined fields hiện hành:** Shared theme đặt nhãn meta12px trong flow, không scale/float hoặc notch; layoutCss.form.labelAfterGap giữ4px từ token hiện có. Label dài/200% tự tăng chiều cao, không chồng giá trị. Toolbar giữ row wrap/min-width theo chữ và alignment cuối; shell.demoControl giữ geometry co giãn của demo selectors, không height/basis lớn trong column mobile. Primitive TextField giữ native/ref/ARIA/validation; không thêm wrapper hay API.

**Khoảng trống thị giác:** CSS gap là khoảng tối thiểu trong flow/grid; space-between, wrap, alignment và chiều cao nội dung có thể tăng khoảng giữa các mép. Contract ghi rõ quan hệ, trục, cách phân bố và điều kiện nội dung đã sẵn sàng; không ép mọi khoảng nhìn thấy bằng CSS gap. Label/helper text bên trong field do theme quản lý, không bù bằng margin/spacer cấp trang. Số cụ thể theo standard/token owner; feature không tạo thang giá trị mới.

Button/TextField/Select/Typography/Alert của MUI tiếp tục dùng một theme. Chỉ extract khi có cùng invariant, owner, API và consumer thật; geometry/behavior cục bộ đúng nghĩa không tự là debt. Geometry hiện có của sáu compositions gồm width/minWidth/maxWidth/height/minHeight/flex/gridColumn; responsive keys xs/sm/md/lg/xl; columns chỉ thuộc SectionGrid. Trong theme hiện hành, sm/md và lg/xl có cùng giá trị breakpoint: kiểm giá trị thật, không giả định có năm ngưỡng khác nhau.
